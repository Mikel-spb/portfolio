Портфолио frontend-разработчика

Читатель

Владелец ИП, самозанятый или небольшое ООО со штатом до 10 человек: частный мастер (электрик, сантехник, отделочник) или фитнес-тренер (йога, пилатес, персональный тренинг) в возрасте 25–50 лет из регионов России и СНГ. Открывает портфолио после отклика на биржах «Профи», Kwork, FL.ru или по письму на электронную почту.

За 60 секунд хочет увидеть:

1. Примеры сайтов в его нише (электрика / сантехника / фитнес / йога).
2. Что сайт приведёт клиентов, а не будет «просто красивым».
3. Что я понимаю специфику его бизнеса и говорю на его языке. Код и технологии не интересуют.

Структура сайта

1. index.html — главная страница с оффером и тремя ведущими кейсами.
2. works.html — список всех работ с фильтром по нишам (Мастера / Фитнес).
3. case-{slug}.html — страница кейса (отдельный файл для каждого кейса).
4. contacts.html — контакты (Telegram + WhatsApp).

Материалы (3 кейса)

Кейс 1: Лендинг электрика «Грамотная электрика»

* Описание: Одностраничный сайт для частного электрика с услугами, прайсом и формой заявки на выезд.
* Стек: HTML + CSS Flexbox, адаптивность.
* Демо: будет опубликовано на GitHub Pages.
* Референс стиля:[Ссылка на похожую работу](грамотная-электрика.рф.)

Кейс 2: Лендинг инструктора БЖЖ с формой записи
* Описание: Одностраничный сайт для инструктора бразильского джиу-джитсу с расписанием тренировок (группы по поясам: белый/синий/пурпурный), ценами и формой записи на пробное занятие.
* Стек: HTML forms + валидация (телефон, возраст, уровень подготовки, наличие травм).
* Демо: будет опубликовано на GitHub Pages.
* Референс стиля:[Ссылка на похожую работу](https://panakhovbjj.ru/#services)

Кейс 3: Каталог услуг сантехника

* Описание: Адаптивный каталог услуг (установка счётчиков, замена труб, монтаж сантехники) с карточками и фильтром.
* Стек: CSS Grid + адаптивность.
* Демо: будет опубликовано на GitHub Pages.
* Референс стиля:[Ссылка на похожую работу](santehnik-aleksandr.ru.)
