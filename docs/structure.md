Портфолио frontend-разработчика

Читатель

Владелец ИП или частный мастер 30–50 лет из регионов России/СНГ. Открывает портфолио через поиск на Kwork или FL.ru. За 60 секунд хочет увидеть: (1) примеры сайтов в его нише (электрика/сантехника/фитнес), (2) что сайт приведёт клиентов, а не будет "просто красивый", (3) что я понимаю специфику его бизнеса и говорю на его языке. Не интересует мой код и технологии.

Структура сайта

1. index.html — главная с оффером и 3 ведущими кейсами
2. works.html — список всех работ с фильтром по нишам
3. case-{slug}.html — страница кейса (отдельный файл для каждого кейса)
4. contacts.html — контакты (Telegram + WhatsApp)
